# 지역아동센터 정기평가 자체점검표

**바로 보기:** https://yoonkwonsong.github.io/community-child-center-evaluation/

**5기 정기평가**(2024~2026년 주기, 기존 시설)를 준비하는 지역아동센터 시설장을 위한 자체점검 도구입니다. 평가지표의 모든 평가항목을 제시하고, 센터가 연도별 충족 여부를 표시하면 『2026년 지역아동센터 평가사업 안내』(평가편람)의 환산 기준에 따라 100점 만점 기준 예상 점수를 산정합니다.

## 주요 기능

화면은 세 가지로 구성됩니다.

- **지표별 점검.** 평가지표(1-1~4-7)별로 카드 1개씩, 모든 평가항목을 행으로 표시합니다. 연도별 항목은 2023·2024·2025년 열로, 수준 평가 항목은 해당 항목의 배점에 맞는 선택지로 표시합니다. 개별 아동 기록은 평가위원이 시설 선정 파일 2개와 무작위 선정 파일 1개를 확인하므로, 시설 선정 2명과 평가위원 선정 1명을 각각 입력합니다. 평가기간을 채운 아동을 우선 선정합니다. 필수 조건, 4-6 회계 관리 감점, 4-7 후원금 관리 기준, 아동학대 사례 감점을 모두 반영합니다.
- **우선순위.** 만점이 아닌 모든 항목을 네 단계(기한 내 작성, 즉시 보완: 충족 여부 항목, 수준 향상: 수준 평가 항목, 보완 불가: 지난 연도 및 감점 사항)로 분류합니다. 항목별로 단독 보완 시 늘어나는 점수를 표시하고, 상단에 현재 입력 기준 보완 후 예상 점수를 보여 줍니다.
- **구비서류·이행사항.** 평가항목의 근거가 되는 문서와 이행사항 47건의 평가 기준 및 관리 권장 주기, 관리 방식(전산·서면), 보관·제출 여부, 주요 내용, 필수 기재 항목을 정리하였습니다. 서식 유형은 **지정 서식**(법정·공식 서식, 희망이음 또는 평가시스템 화면, 타 기관 발급 문서), **예시 서식**(운영 매뉴얼에 예시가 있거나 평가편람에 필수 항목이 제시되어 있으나 양식은 자율), **자유 양식**(실시 사실을 확인할 수 있는 기록)으로 구분하고 분류 근거를 함께 적었습니다. 권장 서식이 있는 28건은 서식 유형에 화살표가 표시되며, 누르면 별도 화면에서 권장 서식을 볼 수 있습니다. 운영 매뉴얼 [예시]와 2026년 평가편람 부록의 서식·참고 자료를 바탕으로 재구성한 빈 서식 66종(분량이 많은 규정과 계획서는 목차, 예시 서식이 없는 프로그램 일지는 작성 지침)을 제공합니다. 한 서류에 서식이 여러 개 있으면 모두 싣고, 서식마다 출처(매뉴얼 판과 [예시] 번호, 평가편람 서식 번호)를 표시합니다. 각 화면에는 평가 확인 사항을 함께 표시합니다. `#form=<서류명>`으로 해당 화면에 바로 연결할 수 있습니다. 영역, 구분, 서식 유형, 보완 시기, 필수 조건, 평가 방식, 확인 방법(현장평가·지도점검·설문조사), 작성 단위로 필터링하고 정렬할 수 있습니다.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `artifact.html` | claude.ai 아티팩트로 게시한 원본 페이지입니다. 모든 수정은 이 파일에서 합니다. |
| `index.html` | 같은 페이지를 독립 HTML 파일로 만든 것으로, GitHub Pages(위 주소)로 게시됩니다. 브라우저에서 바로 열 수도 있습니다. |
| `scripts/make_standalone.py` | `artifact.html`에서 `index.html`을 다시 만듭니다. |
| `tests/scoring_test.py` | 점수 산정 규칙을 31개 사례 및 14개 지표의 전체 환산 경계값에 적용하여 평가편람 환산표와 비교합니다. Node.js가 필요합니다. |
| `tests/ui_audit.py` | Playwright 브라우저 점검: 공동 저장소 모의 저장, 화면을 통한 점수 산정, 세 화면과 권장 서식 화면, 필터·정렬, 휴대전화 화면을 확인합니다. |

## 저장 방식

- **claude.ai 아티팩트에서 사용할 때:** 아티팩트 데이터베이스를 이용하여 **센터별로 하나의 공동 점검표**를 유지합니다. 편집 권한이 있는 모든 사용자가 같은 내용을 보고 수정하며, 보기 권한만 있는 사용자는 읽기 전용으로 봅니다. 다른 센터는 별도의 사본을 사용하여야 합니다.
- **GitHub Pages 또는 파일(`index.html`)로 열 때:** 공동 저장소가 없으므로 표시 내용은 해당 브라우저에만 저장됩니다(`localStorage`).

우선순위 화면의 ‘현재 연도’ 설정은 항상 브라우저에만 저장됩니다.

## 테스트 실행

## 점수 산정 해석 기준

평가편람에 명시되지 않은 부분은 엄격한 해석을 따랐습니다.

- 필수 조건을 충족하지 못한 연도의 프로그램은 해당 연도 점수가 없습니다.
- 확인한 아동 파일 중 하나라도 필수 조건을 충족하지 못하면 해당 지표 전체가 0점입니다.
- 종사자 의무교육은 3개 연도를 모두 충족한 항목만 인정합니다.
- 후원금은 항목별 위반·개선 확인 상태로 계산하며, 개선 후에도 1~2점의 감점이 남고 여러 항목은 합산합니다.

## 한계

- **5기 정기평가 기존 시설** 기준으로만 작성하였습니다. 신규시설은 산정 방식이 다르며, 2027년부터 시작되는 6기 평가에서는 지표가 변경될 수 있습니다.
- 점수는 **자체 추정치**입니다. 평가위원이 질적 수준을 판단하므로 실제 점수는 더 낮을 수 있습니다.
- 필수 기재 항목과 권장 서식은 지역아동센터 전남지원단의 「지역아동센터 운영매뉴얼」 2025년판(제3판, 2024년 12월 발행) 예시 서식을, 희망이음 관련 기준은 2023년 지원사업 안내를 바탕으로 하였습니다. 2025년판에서 빠지거나 다른 서식으로 바뀐 예시(월간사업계획서 [예시 1-11], 안전관리계획서 [예시 1-19], 운영위원회 개최 사진 [예시 1-18], 프로그램 활동사진)는 2024년판에서 가져와 함께 실었습니다. 매뉴얼의 예시는 전남 지역 기준이므로 관할 시도지원단과 시·군·구에 확인하시기 바랍니다.

## 2026년 기준 대조 결과 (2026-10-15)

[지표별 검토·변경·유의사항](docs/2026-standards-audit.md)에 편람 인쇄 쪽수와 함께 기록했습니다. 17개 지표, 환산표, 증빙 인정 기준, 감점·강등 및 관련 화면을 대조했습니다.

- 후원금 개선 후 잔여 감점과 회계 위반 건수를 계산합니다.
- 만족도는 소수점 첫째 자리 반올림 후 구간을 선택하며, 참여자 감점은 아동·보호자 합산 특례를 안내합니다.
- 2023→2024, 2024→2025, 2025→2026 환류와 2025년 특화프로그램의 현장평가 전 공유를 안내합니다.
- 아동 파일 3개를 독립적으로 입력합니다. 기존 ‘충실한 파일 2개’ 값은 시설 선정 1·2로 이전되므로 각각 다시 확인하십시오. 이전 0/1 후원금 값은 유지됩니다.
- 출력물 결재, 희망이음 화면 증빙, 지자체 공문에 의한 서면심의 예외를 반영했습니다.

아동 필수조건 미충족 시 지표 전체를 0점 처리하는 기존 보수적 추정과 종사자 의무교육의 3년 모두 충족 기준은 해석 사항으로 명시했습니다. 편람의 후원금 사용 개선 연도 표기(2025년)는 본문(2026년)과 달라 지자체 확인이 필요합니다. 이 도구는 공식 평가결과를 대신하지 않습니다.
