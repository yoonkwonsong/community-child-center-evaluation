## 공통 변경 및 유지

- 4영역 17지표, 100점, 현장평가 64/지도점검 30/설문 6점 확인.
- 70점 이상 통과, 60~69점 통과(컨설팅 의무), 60점 미만 미통과 유지(12쪽).
- 학대이력 기간을 현장평가 시점에서 **평가연도 2차 확인시점**으로 수정. 사례판단일, 동일사안 병합, 이전 평가 중복반영 제외 명시. 15점 감점 또는 심각한 사안 미통과는 중앙평가위원회 판단(29쪽).
- 내부 출력물 결재 서명·도장 및 중간 결재 필요, 불가피한 미결재 사유, 희망이음 화면 예외, 외부 승인 공문·송수신 기록 인정 추가(89쪽).
- 아동카드 출력물만을 요구하는 표현을 화면 또는 출력물 제시로 수정. 매뉴얼의 권장 사진·서식·보관 방식은 모두 평가 필수요건이 아님을 명시.
- 자체평가 인쇄본 3부·성명 및 등록일 명단·희망이음 열람 장비 유지(27쪽). 현장평가 이의신청 5일/1회 및 사후 보완 불인정 안내 추가(12·28쪽).
- 2026년 환류 확인과 2027년 이후 종료를 구분. 과거 위반을 당초 충족으로 바꾸어 만점 회복하는 우선순위 제안 제거. 미확인 후원금 상황을 포함한 최고점은 조건부 추정임을 표시.
- `artifact.html` 수정 후 `scripts/make_standalone.py`로 `index.html` 재생성. 기존 데이터 키를 유지하고, 두 번째 시설 선정 파일 키를 추가. 0점도 명시적으로 저장·병합하여 다른 파일 점수로 덮이지 않게 수정.

## 명시적으로 남긴 해석 및 한계

1. **아동 필수조건:** 55쪽은 미충족 아동의 해당 지표를 0점 처리한다고 쓰지만, 혼합된 3명 점수 합산 사례를 제시하지 않습니다. 앱의 기존 보수적 해석(선정 3명 중 미충족이 있으면 지표 전체 0점)을 유지하고 추정임을 표시했습니다. 전체 재원아동 중 미선정 아동까지 조건을 넓히던 문구는 선정 3명으로 수정했습니다. 공식 적용은 시도지원단 확인이 필요합니다.
2. **의무교육:** 65쪽은 3년 평가기간과 전원 이수, 항목별 5/0·1/0을 제시합니다. 연도별 부분충족의 별도 평균 산식이 없어 기존의 3년 모두 충족 시 인정 방식을 유지하고 해석임을 표시했습니다.
3. **후원금 사용 개선 연도:** 67쪽 관리 항목은 2026년, 사용 항목은 2025년으로 적혀 있습니다. 원문의 불일치를 임의로 고치지 않고 화면에 표시했습니다. ‘개선 확인’은 지자체가 인정한 경우에만 선택합니다.
4. **이전 입력:** 구버전의 충실한 파일 2명은 같은 점수였으므로 새 두 칸에 복사됩니다. 실제 파일을 각각 재확인해야 합니다. 후원금의 기존 체크 값은 ‘당초 충족’으로 유지되므로 위반 후 개선 사례였다면 직접 변경해야 합니다.
5. **배포:** 이번 변경은 로컬 소스 및 생성 페이지에 적용합니다. GitHub Pages 또는 claude.ai 게시본 반영은 별도 배포가 필요합니다.
